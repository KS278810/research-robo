# ResearchRobo（Research KIT v3.5）

**エンジニアのためのベンチマーク調査ツール。**
AIチャットに渡す1枚のMarkdownで、Deep Researchを単発検索ではなく
**再現可能・監査可能な証拠ベースの調査工程**に変える無料のプロンプトキットです。

紹介サイト: https://ks278810.github.io/research-robo/

## 使い方

LPの「プロンプトをコピー（KIT本文入り）」ボタンを押すと、指示文と[`RESEARCH_KIT_v3.5.md`](./RESEARCH_KIT_v3.5.md)の本文を結合したテキストがクリップボードにコピーされます。Deep Research機能を持つAIチャット（ChatGPT / Claude など）に貼り付けて、編集せずにそのまま送信してください。送信すると、AIが「調べたいこと（調査テーマ）」を質問してくるので、テーマを返信すれば調査が始まります。Geminiは長文の貼り付けが不安定なため、KITファイルをダウンロードして添付する方式でご利用ください。

調査条件と深さ（既定は「普通」）が提示されるので、修正があれば伝え、なければ「進めてください」と返信してください。すると調査プロンプトが1本ずつ提示されます。**新しいチャットを開く必要はありません。**このチャットでDeep Researchモードをオンにしたまま、表示されたプロンプトを1本貼り付けて実行し、終わったら「次へ」と送るだけです。次のプロンプトが続けて提示され、最後の「次へ」で自動的に統合・根拠確認へ進み、レポートが作成されます（「しっかり」「がっつり」を選んだ場合は、検証用の一部プロンプトだけ独立性のため別チャットでの実行をお願いします）。

> 一部のAIチャットは「外部URLを読み込んでその指示に従う」という要求そのものに慎重（間接プロンプトインジェクション対策）で、URLを提示する方式では読み込みに失敗する場合があることを確認しています。本文を直接貼り付ける方式であればこの制限を受けません。

貼り付けがうまくいかない場合は、[`RESEARCH_KIT_v3.5.md`](./RESEARCH_KIT_v3.5.md) をダウンロードしてチャットに添付し、同様の指示文を送ってください。

## できること（4つの技術的特徴）

1. **調べる前に軸を固める** — テーマを書くだけでAIが調査条件（目的・読者・対象・期間・対象外）を仮設定
2. **AIが分担して網羅的に調査** — 調査の深さ（普通/しっかり/がっつり）に応じて自動でWork Packageに分割し、同じチャットの中で1本ずつ実行できる調査プロンプトを生成（独立性が必要な検証用プロンプトだけ別チャット用に生成）
3. **根拠のある情報だけ使う** — 出典位置・原文抜粋つきの構造化データで結果を回収し、Blind Evidence Auditで数値・帰属を検査
4. **そのまま渡せるレポートに** — 監査を通った事実だけで、出典番号つきのレポートを構成
